Wombat

WireGuard®, AmneziaWG, Cisco AnyConnect and Tailscale in one app: the last VPN software you need.

A native, free and open-source VPN client for macOS. Secure first, easy and beautiful to use, and powerful when you need it, with a command line developers will actually use.

Why another WireGuard app

The official macOS client has been effectively abandoned since early 2023. The alternatives are either not native, not pretty, or not free. Wombat is a modern replacement that feels like part of macOS, imports your existing tunnels in a minute (including the official app's Export Tunnels to Zip), and never needs a root helper.

1 · Security

Security comes first

Every design decision starts here: where your keys live, what runs as root, what a config file is allowed to do, and what any other program on your Mac can change.

  • No root helper

    No privileged daemon and no sudoers rules. The tunnel runs only inside Apple's sandboxed Network Extension.

  • Keys stay private

    Configs live in your keychain and in a root-only store, never in the VPN preferences file every user can read. The extension never hands a key back, and keys never reach the logs.

  • Leak protection by default

    Full-tunnel configs get the kill switch and a blocked local network out of the box, guarding against TunnelVision and LocalNet attacks. A full tunnel that covers only IPv4 blocks IPv6 instead of leaking it.

  • Configs can't run code

    PostUp, PreDown and friends are flagged and ignored. A downloaded config can never execute a command.

  • The CLI can't weaken you quietly

    Imports, deletes, renames, switching tunnels and anything that lowers protection from the command line need your approval or Touch ID in the app.

  • Signed, end to end

    Developer ID signed and notarized, with the hardened runtime. The app, the extension and the CLI check each other's code signatures before they talk, and updates are signed on top.

  • Safe on shared Macs

    Each macOS user sees and starts only their own tunnels, even though VPN settings are system-wide. An on-demand tunnel that comes up at the login window stops when another account takes the screen (a sign-in over SSH doesn't stop it).

  • A current engine

    Built on current wireguard-go (October 2026), not the 2023 one the official app still ships, plus our own fixes for crashes and sleep.

  • AnyConnect, walled off

    Cisco VPNs run in a separate system extension that never holds a WireGuard key. Sign-in is Wombat's own Swift code, and gateways that demand a host scan are refused: nothing a server sends is ever run.

2 · Easy and beautiful

Feels like part of macOS

A SwiftUI app and menu bar item that look and behave like Apple made them. Import your tunnels in a minute and see exactly what each one does.

  • Truly native

    Tunnels live in Apple's Network Extension: they show in System Settings and keep running with the app closed.

  • Import anything

    Drop in .conf files, a zip of them (including the official app's export), paste from the clipboard, or scan a QR code with the camera. AmneziaWG configs work too, on their own engine.

  • Live status

    Handshakes, endpoints and transfer per peer, in the window and the menu bar.

3 · Powerful

Powerful when you need it

Automatic connections, a config linter, and a complete command line for scripts, CI and coding agents.

  • On demand

    Connect automatically on Wi-Fi and Ethernet, except on networks you trust. macOS runs the rules, even with the app closed.

  • Kill switch

    Traffic goes only through the tunnel, also while it reconnects (within what macOS allows; see the docs), with an option to allow the local network.

  • Config review

    Catches DNS leaks, IPv6 leaks, overlapping AllowedIPs, DNS servers outside the tunnel and ignored PostUp scripts.

  • A real CLI

    Every action from the terminal, JSON output, a linter with CI exit codes, wg-compatible key tools, log streaming, shell completions and a skill for coding agents.

  • AmneziaWG

    For networks that block WireGuard: AmneziaWG 1.0 to 2.0 configs import and connect, with junk packets, padding and custom headers. They run on their own engine, and plain tunnels never touch it.

  • Homebrew

    brew install --cask ventz/tap/wombat-wireguard installs the app and puts wombat on your PATH, no sudo needed. Installing by the full name trusts just this cask, as Homebrew 6 and later require.

4 · Cisco AnyConnect

Your work VPN, in the same app

Most universities and companies run Cisco AnyConnect (Cisco Secure Client). Wombat connects to those gateways too, through OpenConnect, so one app covers your own WireGuard servers and your work or campus VPN. No Cisco client needed.

  • Sign in your organization's way

    Password, Duo (push, phone call or passcode), single sign-on (Okta, Entra ID, Duo SSO and other SAML providers), or a client certificate from your keychain.

  • Single sign-on in your own browser

    SSO opens in your default browser, so passkeys, password managers and an existing session just work. Prefer to keep it separate? Each VPN can sign in inside Wombat instead, with its own cookies. Either way the sign-in shows right on the VPN's screen, no pop-up windows.

  • The gateways you already have

    Cisco ASA and Firepower, and the open-source ocserv. DTLS keeps it fast, and Wombat always negotiates the best TLS the gateway offers, back to the older ones it still accepts.

  • Its own sandbox

    OpenConnect runs in a second system extension that never holds a WireGuard key. The session token lives only in memory, and the tunnel accepts only the gateway certificate macOS trusted when you signed in.

  • Nothing from the server runs

    Gateways that demand a Cisco host scan (HostScan/CSD) are refused rather than run. Wombat's build of OpenConnect also carries fixes for memory-safety bugs we found and reported upstream.

  • Shareable profiles

    Export a VPN as an .anyconnect file for colleagues, with no secrets inside, or script it: wombat import work.anyconnect, then wombat up work.

5 · Tailscale Preview

Your tailnet, without another app

Wombat joins Tailscale tailnets, and tailnets run by Headscale, your own open-source coordination server. Sign in once in your browser, and your devices are reachable by their tailnet address and their MagicDNS name. New in 1.4 as a preview: the essentials work, and more is coming.

  • Tailscale or your own server

    Use Tailscale's coordination server, or point Wombat at a Headscale on your own https address. Each server gets its own node and its own keys; keys never move between servers.

  • Sign in your way

    Sign-in opens in your default browser, so your identity provider, passkeys and password manager just work. The page opens only when you click, and only on your coordination server's own address.

  • MagicDNS, kept to your tailnet

    Names like nas.your-tailnet.ts.net resolve through the tailnet; everything else stays on your Mac's own DNS. A server can't claim domains that aren't the tailnet's, and once a tailnet has a DNS name it can't quietly switch to another.

  • Only tailnet traffic

    Wombat checks everything the coordination server proposes before macOS sees it: tailnet addresses and routes only, never a default route, never another network's DNS. Tailnet Lock is kept on disk, so a compromised server can't switch it off.

  • Its own sandbox

    Tailscale's engine runs in a third system extension, apart from your WireGuard keys and from AnyConnect, as root-only state that never leaves it. Its SSH, Taildrop, web and debug servers are compiled out, and it can't start other programs.

  • What the preview leaves out

    Exit nodes, subnet routes, on-demand and command-line control come later. macOS runs one VPN at a time, so connecting a tailnet switches off your other tunnel, as with any VPN app.

6 · Accessible

Built for everyone

A VPN is something you need to trust at a glance. Wombat's interface is audited against WCAG 2.2 AA (as applied to Mac apps), and the findings are fixed before release.

  • VoiceOver throughout

    Every control is labeled. Connecting, disconnecting, imports and errors are announced, and so is each step of a VPN sign-in: Duo prompts, wrong passwords and gateway messages.

  • Keyboard first

    Works from the keyboard, including Full Keyboard Access, with shortcuts for the common actions (⌘N new tunnel, ⌘O import, ⇧⌘V paste). Sign-in forms put focus in the first empty field: Return signs in, Escape cancels.

  • Not by color alone

    Each tunnel's status has its own symbol shape as well as its color, in the window and the menu bar. Text colors are checked for contrast in light and dark mode, and selection gets stronger with Increase Contrast.

  • Sign-in without hurdles

    Paste is never blocked, password managers and AutoFill fill the fields, and there are no puzzles: sign-in follows WCAG's accessible authentication rule.

  • Safe prompts

    Approval dialogs make Cancel the default, so a stray Return never approves anything, and they bounce the Dock icon so a request isn't missed.

  • Plain words

    Errors and warnings say what happened and what to do next, not an error code, and the import review explains each risk it finds in a config.
